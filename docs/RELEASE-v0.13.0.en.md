# HighWall 0.13.0 Stable-path rehearsal

This is a Stable-channel rehearsal release in the disposable public validation repository. It exists only to exercise the stable GitHub Release `latest` marker, the stable image `0.13` tag, package versioning, and the hosted publishing flow. It is not a production HighWall release and adds no capability or production-readiness claim.

Validation focus:

- `v0.13.0` maps to the stable channel and Python package version `0.13.0`;
- the GitHub Release uses the stable title and is marked `latest`;
- the image publishes `0.13.0`, `0.13`, and commit-SHA tags;
- release assets continue to include `SHA256SUMS`, build proofs, SBOMs, and attestations.

The formal project acceptance boundary remains unchanged: this version must not be described as production-ready, C4, or independently audited.
