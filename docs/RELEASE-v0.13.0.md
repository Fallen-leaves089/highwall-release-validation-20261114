# HighWall 0.13.0 Stable 路径演练

这是临时公开验证仓库中的 Stable 通道演练版本，仅用于验证正式版 Release 的 `latest` 标记、稳定镜像的 `0.13` 标签、包版本和托管发布流程。它不是正式 HighWall 发布，不增加能力或生产可用性声明。

验证重点：

- `v0.13.0` 映射为稳定通道和 Python 包版本 `0.13.0`；
- GitHub Release 使用正式版标题并设置为 `latest`；
- 镜像发布 `0.13.0`、`0.13` 和 commit SHA 标签；
- Release 资产继续附带 `SHA256SUMS`、构建证明、SBOM 和 attestation。

本版本沿用正式项目的未验收边界：不得据此宣称生产可用、C4 或通过第三方安全审计。
